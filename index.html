LABORATORY COURSEWORK

Theory, Architecture & Methodology

FUNDAMENTAL PRINCIPLE
“Text-to-speech is a technology that converts written text into synthesized human speech.”

Speech synthesis bridges the gap between discrete linguistic symbols (letters, numbers, tokens) and continuous acoustic pressure waves that emulate the physiological human vocal tract.

01

Text Normalization (NLP Frontend)

Raw text contains non-standard words (NSWs), punctuation, abbreviations, numbers, dates, and symbols. The NLP frontend normalizes:

  • Number Expansion: Translates "2026" into "twenty twenty-six" or "two thousand twenty-six" based on context.
  • Acronym Expansion: Differentiates "Dr." (Doctor/Drive) and "St." (Street/Saint).
  • Punctuation Tokenization: Maps commas and periods to physiological pause intervals.
02

Grapheme-to-Phoneme (G2P)

Converts written alphabet sequences (graphemes) into phonetic sound representations (phonemes):

  • Phonetic Transcriptions: Maps words to the International Phonetic Alphabet (IPA) or Arpabet symbols.
  • Homograph Disambiguation: Accurately chooses pronunciations for words like "wind" (breeze vs. coil) or "read" (present vs. past).
  • Pronunciation Lexicons & ML: Combines dictionary lookups with neural sequence models for out-of-vocabulary terms.
03

Prosody & Acoustic Modeling

Natural speech requires rhythm, emphasis, melody, and emotional pitch variation:

  • Pitch Contour (F0): Predicts fundamental vocal cord vibration frequency throughout the sentence.
  • Phone Duration: Calculates millisecond timing for vowels and consonants.
  • Stress & Intonation: Raises pitch and volume on interrogative inflection (questions vs. declarative assertions).
04

Acoustic Synthesis & Vocoders

The final stage converts phonetic and prosodic features into physical pressure waveforms:

  • Concatenative Synthesis: Slices and concatenates pre-recorded human speech diphones.
  • Formant Synthesis: Synthesizes speech mathematically by modeling vocal tract acoustic resonances.
  • Neural Vocoders (Modern): Models like WaveNet, Tacotron 2, and HiFi-GAN generate high-fidelity 24kHz/48kHz raw audio.

Browser Web Speech API Architecture (`SpeechSynthesis`)

W3C Community Group Spec

1. SpeechSynthesis Singleton (`window.speechSynthesis`)

The controller interface for the synthesis service in the browser. It manages the utterance speech queue, hardware audio channel access, and exposes global methods:

// Global controller methods speechSynthesis.speak(utterance); // Queues utterance for speech speechSynthesis.pause(); // Pauses ongoing playback speechSynthesis.resume(); // Resumes paused playback speechSynthesis.cancel(); // Stops and clears queue speechSynthesis.getVoices(); // Retrieves list of system voices

2. SpeechSynthesisUtterance Object

Encapsulates the text content, linguistic configuration, and event listeners for each individual spoken phrase:

const utterance = new SpeechSynthesisUtterance(text); utterance.voice = selectedVoice; // SpeechSynthesisVoice object utterance.rate = 1.0; // 0.1 to 10 (normal is 1.0) utterance.pitch = 1.0; // 0 to 2 (normal is 1.0) utterance.volume = 1.0; // 0.0 to 1.0 utterance.onstart = () => updateStatus('Speaking'); utterance.onboundary = (e) => highlightWord(e.charIndex); utterance.onend = () => updateStatus('Finished');
